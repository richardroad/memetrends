# ЛУЧ-3000

Визуальный синтезатор для концертов и диджей-сетов. Пишешь словами, какой нужен визуал, а ИИ собирает его из библиотеки стилей или создаёт новый стиль кодом. Работает в браузере в реальном времени и реагирует на трек.

## Как устроено

```
промпт ─► ИИ-режиссёр ─► пресет (стиль + параметры + палитра + оптика)
       └► кузница ────► новый стиль (GLSL) ─► проверка компиляции ─► библиотека

трек / демо-сигнал ─► анализ (спектр, волна, бас/середина/верх, бит, BPM)
                                   │
стиль A ─┐                         ▼
         ├─► переход ─► оптика (шлейф, зум, вращение, свечение, RGB-сдвиг) ─► экран (развёртка, зерно)
стиль B ─┘
```

| Файл | Что внутри |
|---|---|
| `index.html` | Интерфейс бортовой консоли: разметка и стили |
| `engine.js` | Движок WebGL2: сборка шейдеров, буферы, переход A→B, оптика, миниатюры, проверка кода |
| `styles.js` | Встроенная библиотека стилей |
| `app.js` | Анализ звука, такт, модуляция, эффекты, библиотека и хранилище, ИИ-режиссёр, кузница, MIDI, скины, запись |
| `skins.js` | Скины интерфейса |

## Контракт стиля

Стиль это объект в `styles.js` (или документ в базе для стилей из кузницы):

```js
{
  id: "vortex",
  name: "Вихрь",
  description: "Одно предложение: как выглядит и как реагирует на музыку. ИИ-режиссёр выбирает по нему.",
  tags: ["вихрь", "спираль"],
  params: [{ name: "Скорость", def: .4 }],        // до 8, значения 0..1, в коде P0..P7
  palette: ["#010203", "#1d3557", "#a8dadc", "#f1faee"], // от тёмного к яркому
  post: { trail, zoom, twist, bloom, chroma, scan },     // оптика по умолчанию, 0..1
  glsl: `vec3 render(vec2 p){ ... }`
}
```

`render(p)` получает центрированные координаты: `y` от −0,5 до 0,5, `x` растянут по соотношению сторон. Возвращает RGB.

Движок даёт:

| Имя | Что это |
|---|---|
| `uTime` | время в секундах |
| `uBass`, `uMid`, `uHigh`, `uLevel` | полосы и общий уровень, 0..1, сглажены |
| `uBeat` | 1 на бите, затухает к 0 |
| `P0`…`P7` | параметры стиля, 0..1 |
| `uPal[4]`, `ramp(t)`, `cyc(t)` | палитра, градиент и циклическая палитра |
| `spec(x)` | спектр в логарифмической шкале, x=0 бас, x=1 верх |
| `wave(x)` | форма волны, −1..1 |
| `prev(uv)` | предыдущий кадр |
| `hash`, `noise`, `fbm`, `rot` | шум и поворот |

Правила: цвет только через палитру (чтобы работали пресеты), чёрный фон доминирует (LED), циклы с постоянной границей не больше 64 итераций, 60 кадров в секунду на 1080p.

## Как добавить стиль

1. **Через кузницу.** Переключи «Запрос» на «Создать стиль» и опиши его. ИИ напишет код, проверит компиляцию в движке и положит стиль в библиотеку.
2. **Руками.** Добавь объект в `styles.js` по контракту выше.

## Хранилище

Стили из кузницы и пресеты лежат в общей базе артефакта: коллекции `styles` и `presets`. Если база недоступна, всё сохраняется в браузере.

## Живое управление

**Детектор.** Спектр делится на бас, середину и верх. У каждой полосы свой повторитель огибающей с атакой и затуханием, как у компрессора, и авто-усиление (АРУ), которое подстраивает уровень под громкость трека. Отдельно ищутся атаки (spectral flux): удары, щелчки, начала нот.

**Такт.** Часы держат темп и долю: темп по треку (мягкая подстройка фазы под бочку), тап-темп, ручная подстройка ±1. Переходы между пресетами можно квантовать: сразу, на бит, на такт. Автопилот переключает пресеты каждые 4/8/16/32 такта.

**Матрица модуляции.** Источники: бас, середина, верх, уровень, бит, фаза такта, LFO 1 и 2 (форма и период в долях такта), случай (новое значение на каждый бит), атака. Цели: любые параметры стиля и оптики. Глубина от −100 до 100, прибавляется к базовому значению. Живое значение видно на крутилке янтарной дугой. Связи хранятся в пресете, ИИ-режиссёр сам их предлагает.

**Эффекты (пэды).** Строб (16-е доли), стоп-кадр, инверсия, зеркало, удар зума (на каждый бит), RGB-взрыв. Держать клавишу, Shift фиксирует.

**Деки A/B.** Авто-переход по времени или ручной кроссфейдер: выбираешь следующий пресет, он встаёт в деку B, ведёшь фейдер.

**MIDI.** «MIDI-назначение» → нажать крутилку или пэд → покрутить ручку или нажать клавишу на контроллере. Назначения хранятся в браузере. Работает, если браузер и окно дают доступ к MIDI.

## Эпохи и символика

Третий слой поверх стиля и оптики, тоже часть пресета и тоже модулируется звуком.

**Линзы эпох** перерисовывают любой стиль в другой материал: ASCII (терминалы 1970-х), 8 бит с дизерингом (1980-е), растр поп-арта (1960-е), витраж (готика), смальта с золотом (Византия), гравюра штрихом (XVI век), VHS (1990-е), кинохроника (1920-е), пуантилизм (1880-е), тепловизор, неон-контур.

**Символика** накладывает знаки: руны, алхимия и планеты, зодиак, сакральная геометрия, катакана, старославянская азбука, машинный код, знаки «Борт-3000». Режимы: дождь, орбита (кольца вокруг центра, вращаются, бас раздувает), сетка (знаки меняются на бит), большой знак (новый на каждый такт). Знаки рисуются системными шрифтами: если набор отображается квадратиками, в системе нет нужного шрифта.

**Случай** собирает случайную комбинацию: стиль × палитра эпохи × линза × знаки × связи модуляции. 17 стилей × 12 линз × 8 наборов знаков × 5 режимов × 14 палитр дают больше ста тысяч сочетаний, а крутилки и модуляция делают каждое живым.

## Живой вход (микрофон, линейный вход)

Кнопка «Вход» берёт звук с микрофона или со звуковой карты (линейный выход диджейского пульта). Окно claude.ai не даёт странице микрофон, поэтому вход работает, когда ЛУЧ-3000 открыт отдельно:

1. Скачай папку `luch3000` из репозитория.
2. Открой `index.html` в Chrome.
3. Нажми «Вход» и разреши доступ.

Вне claude.ai нет ИИ (подбор работает автономно по словам, «Случай» работает полностью) и база пресетов живёт в браузере.

## Скины

Скин это объект в `skins.js`: набор CSS-токенов (`vars`) и необязательный CSS поверх (`css`). Токены: цвета корпуса, краёв, текста, фосфора, действий, модуляции; градиенты кнопок; цвета крутилок; срез углов `--cut`, скругление `--radius`; шрифты. Сгенерированный скин достаточно описать в этом формате.

Тестовые скины: «Борт-07» (ночная консоль), «Аква-2001» (глянцевый пластик нулевых), «Фосфор» (янтарный терминал).

## Управление

| Клавиша | Действие |
|---|---|
| `Ctrl/⌘ + Enter` | синтез по запросу |
| `1`–`9` | вызвать стиль или пресет из открытой вкладки библиотеки |
| `←` `→` | предыдущий / следующий |
| `S` | режим «Сцена»: спрятать пульт |
| `B` | затемнение |
| `F` | полный экран |
| `Пробел` | пауза трека |
| `T` | тап-темп |
| `Q W E R A D Z X C` | эффекты: строб, стоп-кадр, инверсия, зеркало, удар зума, RGB-взрыв, калейдоскоп, пиксели, эхо (Shift фиксирует) |
| `Esc` | отменить назначение модуляции или MIDI |

Крутилки: тянуть вверх-вниз (с Shift точнее), колесо, стрелки; двойной клик сбрасывает к значению стиля.
